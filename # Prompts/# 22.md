
# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
**Context:** The current settings UI is cluttered with inline text descriptions and inconsistent layouts. The project currently lacks standardized UI primitives.
**Objective:** 1. Architect reusable `Modal` and `Tooltip` components from scratch.
2. Refactor the Transpose and Output settings into clean, absolute-positioned modals accessed via a Settings Cog.
3. Replace inline descriptions with hover-state Tooltips.
4. Fix a CSS margin regression on the Output card and align its Settings Cog with the Transpose card.

## 2. Technical Decisions & Dependencies
* **UI Primitives:** Create a new directory `src/components/ui/`. The agent must build a pure React/Tailwind `Modal.tsx` (using standard absolute positioning, z-index, and click-outside-to-close logic) and `Tooltip.tsx` (using group-hover Tailwind utilities). Do **not** install external libraries for this unless absolutely necessary for accessibility.
* **Component State:** The modals will be controlled via local state (`isSettingsOpen`) within `TransposeKeyboard88.tsx` and `NoteRangeFilterKeyboard.tsx`.
