# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
You are building a "MIDI Transposer" application that orchestrates three existing React components (`KeySplitKeyboard`, `TransposeKeyboard88`, `NoteRangeFilterKeyboard`) into a unified vertical stack. You will build an application shell that manages Web MIDI API connections, handles a global Bypass state, provides an explicit "Panic" feature, and processes incoming MIDI signals sequentially through the logic of all three components before sending them to MIDI outputs.

## 2. Technical Decisions & Dependencies
* **State Management:** Use `zustand` to manage the global MIDI pipeline configuration (Bypass, Active Channels, current Zones, Transpose Amount, Filter Mode, Filter Range).
* **Icons:** Use `lucide-react` for header buttons (Power, Info, Settings, TriangleAlert for Panic).
* **Styling:** Standard Tailwind CSS. The app must be forced into Light Mode (white backgrounds, dark text). Modals must be built using native React state and Tailwind fixed overlays (no external modal libraries).
* **Core Algorithm (The MIDI Pipeline):**
  When a MIDI Note On (0x90) or Note Off (0x80) is received:
  1. **Bypass Check:** If `bypass === true`, send untouched to output.
  2. **Channel Filter:** If the incoming note's channel is NOT in `activeChannels`, send untouched to output (do not process).
  3. **Split Stage:** Check if the note falls within any active `Zone`. If yes, apply the zone's `octave` shift (`note += zone.octave * 12`) and map to `zone.channel`. If no zone matches, drop the note (or pass through based on strict strictness; we will drop it if unassigned to a split, as per split logic).
  4. **Transpose Stage:** `note += transposeAmount`.
  5. **Filter Stage:** * `block`: If `note < min` or `note > max`, drop it.
     * `limit`: `note = Math.max(min, Math.min(max, note))`.
     * `octave_wrap`: If out of range, `while (note < min) note += 12; while (note > max) note -= 12;`. If `max - min < 12` and it still doesn't fit, drop it.
     * `wrap`: `rangeSize = max - min + 1`. `note = min + ((note - min) % rangeSize)`. If `note < min`, `note += rangeSize`.
