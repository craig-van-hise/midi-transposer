# Product Requirements Prompt (PRP) — KEYBOARD UI STANDARDIZATION 🔘

## 1. Context & Objective
**STATUS: UI COMPONENT MERGE**
The three keyboard components currently use divergent CSS styling for their piano beds. The objective is to unify all three keyboards using a specific hybrid styling model. 

The master hybrid model requires:
1. **White Keys:** Dark borders (`#7a7a7a`) and dark, high-contrast C-note labels (modeled from `TransposeKeyboard88`).
2. **Black Keys:** 3D beveled appearance using lighter gray tops and jet-black heavy bottom borders (modeled from `NoteRangeFilterKeyboard`).
3. **Container:** A soft drop shadow around the entire piano bed wrapper (modeled from `NoteRangeFilterKeyboard`).

## 2. Technical Style Specifications
You must apply these exact CSS rules to the base states of the keys across all three files. 
*Note: You must preserve the dynamic background color logic (e.g., active zones, selected transpose note), but base/inactive states must map to these values.*

* **White Key Base:**
    * `backgroundColor`: `'#ffffff'` (unless overridden by active state)
    * `borderLeft`, `borderRight`, `borderBottom`: `'1px solid #7a7a7a'`
    * `borderTop`: `'none'`
    * `borderBottomLeftRadius`, `borderBottomRightRadius`: `'4px'`
* **White Key C-Note Text:**
    * `color`: `'#111827'` (gray-900)
    * `fontWeight`: `'600'`
    * `fontSize`: `'10px'`
* **Black Key Base (3D Effect):**
    * `backgroundColor`: `'#3a3a3a'` (unless overridden by active state. If active, use the active color here, but keep the borders below intact).
    * `borderBottom`: `'8px solid #050505'`
    * `borderLeft`, `borderRight`: `'2px solid #050505'`
    * `borderTop`: `'none'`
    * `borderRadius`: `'0px'`
* **Piano Bed Wrapper:**
    * `boxShadow`: `'0 4px 10px rgba(0,0,0,0.2)'`
