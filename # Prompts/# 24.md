# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
**Feature:** "Smart Wrap" Filter Mode. 
**Objective:** Add a 5th output filter mode that wraps out-of-bounds notes to the opposite end of the active range, while strictly preserving the note's original pitch class (C to C, C# to C#, etc.). 

## 2. Technical Decisions & Dependencies
* **Algorithm (Smart Wrap):** The agent must use safe positive modulo arithmetic to derive the pitch class, and project it onto the boundaries.
    * If wrapping over the `max`, calculate the lowest note $\ge min$ with the same pitch class.
    * If wrapping under the `min`, calculate the highest note $\le max$ with the same pitch class.
    * **Failsafe:** If the range `[min, max]` is narrower than an octave (meaning the target pitch class physically does not exist within the boundary), the note must be cleanly dropped (`shouldDrop = true`) rather than mis-mapped.

       ```typescript
       } else if (filterMode === 'smart_wrap') {
         if (finalNote < min || finalNote > max) {
           // Safe positive modulo for pitch class (0-11)
           const pc = ((finalNote % 12) + 12) % 12; 
           
           if (finalNote > max) {
             // Exceeded top. Find lowest valid note at the bottom.
             let wrapped = min - (min % 12) + pc;
             if (wrapped < min) wrapped += 12;
             
             if (wrapped <= max) {
               finalNote = wrapped;
             } else {
               shouldDrop = true; // Pitch class does not exist in this narrow range
             }
           } else if (finalNote < min) {
             // Exceeded bottom. Find highest valid note at the top.
             let wrapped = max - (max % 12) + pc;
             if (wrapped > max) wrapped -= 12;
             
             if (wrapped >= min) {
               finalNote = wrapped;
             } else {
               shouldDrop = true;
             }
           }
         }
       }
       ```
